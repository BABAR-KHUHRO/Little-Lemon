# Little Lemon – Meta Front-End Developer Capstone

A responsive restaurant web application developed as the capstone project for the **Meta Front-End Developer Professional Certificate** on Coursera.

The project is based on **Little Lemon**, a fictional Mediterranean restaurant, and focuses on building a modern front-end experience using React. The application includes a table reservation workflow and applies front-end development concepts covered throughout the Meta Front-End Developer program.

## Project Overview

The Little Lemon project was developed to demonstrate practical front-end development skills through a complete React application.

The project focuses on:

* Responsive and user-friendly interface design
* React component-based development
* Semantic HTML structure
* CSS styling and responsive layouts
* Table booking functionality
* Form handling and validation
* API interaction
* Unit testing
* Accessibility
* User experience and usability
* Git and version control

## Technologies Used

* **React**
* **JavaScript**
* **HTML5**
* **CSS3**
* **Git / GitHub**

## Key Features

### Table Reservation

Users can interact with the table reservation system and provide the required booking information through the application's booking interface.

### Responsive Design

The application is designed to provide a consistent experience across different screen sizes and devices.

### Form Validation

The booking form includes validation to help ensure that user-provided information is handled correctly.

### API Integration

The project demonstrates querying and submitting booking information through an API.

### React Components

The application is structured using reusable React components, allowing different parts of the interface to be developed and maintained independently.

### Accessibility & Usability

Accessibility and user experience were considered throughout the project, including semantic structure, usability evaluation, and improvements based on the project's requirements.
